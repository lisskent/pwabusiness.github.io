# Мой заработок — iPhone PWA

Готовое офлайн web-приложение для учёта заработка.

## Возможности
- Смена / Усиление
- Наличные, безнал, часы
- Автоматический расчёт: часы × ставка + (наличные + безнал) × 3%
- Усиление: часы × ставка усиления
- Месячная статистика и список дней
- Календарь текущего месяца с отметками смен и усилений
- Заметки на конкретную дату
- Время напоминания
- Настройки ставок
- Очистка текущего месяца с подтверждением
- Данные сохраняются локально на iPhone
- Работает офлайн после первого открытия

## Установка на iPhone
1. Разместите папку на HTTPS-хостинге.
2. Откройте сайт в Safari.
3. Нажмите «Поделиться» → «На экран Домой».
4. Запускайте приложение с иконки.

## Важно про напоминания
Без сервера PWA не может гарантированно выполнять произвольные локальные уведомления, когда iOS полностью выгрузил приложение. В этой версии напоминание проверяется, пока приложение работает, и используется Notification API при доступном разрешении. Для настоящих фоновых уведомлений нужен Push-сервис и небольшой backend.
