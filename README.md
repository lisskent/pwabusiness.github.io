# Мой заработок v3 — iPhone PWA

Офлайн PWA для учёта заработка бариста.

## Что добавлено
- Явные цвета календаря: синий = смена, розовый = усиление, серый = выходной.
- Повторное нажатие активной кнопки режима выключает режим.
- Повторное нажатие на уже отмеченный день в активном режиме снимает отметку.
- В режиме без выделения нажатие даты выбирает день для заметки и редактирования.
- Редактирование любого сохранённого дня, включая прошлые даты и прошлые месяцы.
- Отдельная ставка сохраняется внутри каждой записи, поэтому изменение ставки не пересчитывает историю.
- Карточка дня: тип, выручка, часы, ставка, итог и удаление записи.
- Статистика месяца: общий заработок, усиления, часы, рабочие дни, средний день и средний час.
- Статус «Выходной» в календаре.
- Навигация по месяцам.
- Экспорт и импорт JSON-резервной копии.
- Розовая карточка «Заработок сегодня» с пользовательским изображением справа.
- Заметки и время напоминания.

## Установка
Разместить папку на HTTPS-хостинге, открыть в Safari и выбрать «Поделиться → На экран Домой».

## Напоминания
PWA без серверной части не может гарантировать выполнение произвольного JavaScript в фоне после полной выгрузки iOS. Пока приложение работает, время проверяется и при наличии разрешения используется Notification API. Для гарантированных фоновых push-уведомлений нужен небольшой backend.

## Резервные копии
В Настройки → Резервная копия можно экспортировать JSON. Импорт заменяет текущие данные после подтверждения.
